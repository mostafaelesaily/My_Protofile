About

Focused on systems that hold up under real use.

I'm a backend developer working mainly with C# and ASP.NET Core Web API. My focus is on building RESTful APIs that are secure, scalable, and easy to maintain — using Clean Architecture, SOLID principles, and well-tested patterns like Repository and Unit of Work.

Most of my work centers on the parts of an application that aren't visible but matter most: authentication, data access, caching, real-time communication, and deployment. I care about writing code that the next developer — often future me — can actually understand and extend.

Alongside development, I've spent time teaching backend and frontend fundamentals to other students, which has sharpened how I explain and structure technical decisions.
